## 주요 변경

- **첫 실행 안내**: 새로 설치하면 언어·계정·저장 위치·화면·프롬프트 설정을 차례로 고르는 안내 화면이 뜹니다. 이전 버전 백업도 여기서 바로 가져올 수 있습니다. 기존 사용자에게는 뜨지 않습니다.
- **디렉터 도트화 도구**: 이미지 전체를 픽셀 아트로 바꾸는 로컬 도구를 추가했습니다. 도트 크기·색 수(8~1024)·디더링·톤 프리셋을 고를 수 있고 Anlas를 쓰지 않습니다. 디렉터 도구는 이제 옆에서 밀려 나오는 페이지로 열립니다.
- **V5 사용량 표시**: 오푸스 부스트(Extra Usage)를 따로 표시하고, 하루 충전 속도와 만료된 구독도 보여 줍니다. 기본 게이지가 0%여도 부스트가 남아 있으면 소진으로 보지 않아 다른 계정으로 넘어가지 않습니다.
- **계정 자동 전환 끄기**: 계정이 2개 이상이면 계정 설정에 "계정 자동 전환" 스위치가 생깁니다. 끄면 게이지가 바닥나도 지금 계정으로 계속 생성합니다 (Anlas 사용).
- **프롬프트 프리셋 파라미터 뒤섞임 수정**: 파라미터가 저장되지 않았거나 일부만 저장된 프리셋으로 바꾸면 직전 프리셋의 스텝·샘플러 등이 남고, 프롬프트를 고치면 그 값이 새 프리셋에 저장되던 문제를 고쳤습니다. 이제 저장되지 않은 값은 모델 기본값으로 채웁니다. 앱 시작이 느릴 때 활성 프리셋이 기본값으로 덮이던 문제도 고쳤습니다.
- **NAIS2 씬 JSON 불러오기**: NAIS2에서 쓰던 씬 JSON을 모두 불러옵니다 — NAIS2 씬 내보내기, `scene_preset_export.json`, 상호작용 공유용(슬롯 조합), SDImageGenEasy 프리셋. 읽을 수 없는 파일은 이유를 알려 줍니다.
- **씬 예약 취소 복원**: 예약해서 큐로 넘긴 씬 생성을 취소하면 예약이 원래 씬·캐스트로 돌아옵니다. 생성 중에 새로 넣은 예약은 그대로 유지됩니다.
- **같은 초에 저장된 이미지 덮어쓰기 수정**: 업스케일·디렉터·로컬 편집처럼 시드가 같은 이미지를 같은 초에 저장하면 앞 이미지가 덮어써지던 문제를 고쳤습니다. 이제 `_2`, `_3`…으로 따로 저장됩니다.
- **업그레이드 안정성**: DB 마이그레이션을 별도 스레드에서 실행해, 큰 작업 공간을 업그레이드하는 중 앱을 다시 실행해도 업그레이드가 끊기지 않습니다. 업그레이드 진행 창이 화면에 남는 문제도 고쳤습니다.

## 기존 사용자 데이터

이번 버전은 데이터베이스 스키마 **v20을 유지**합니다. 1.0.28·1.0.29에서 업데이트하면 마이그레이션 없이 바로 열립니다. 1.0.27 이하에서 업데이트하면 v18에서 v20으로 올라가며, 업그레이드 전에 기존 DB가 자동 백업됩니다.

## Highlights

- First-run onboarding for new installations: language, account, storage, appearance and prompt setup, plus importing an earlier backup. Existing users don't see it.
- A local pixel art tool in Director (dot size, 8–1024 colors, dithering, tone presets; no Anlas). Director tools now open as slide-in side pages.
- The V5 usage chip shows Opus boosts (Extra Usage), the daily refill rate and expired subscriptions. A 0% regular gauge with boost left no longer counts as exhausted, so it no longer switches accounts.
- A "Switch accounts automatically" toggle (shown with two or more accounts). Turned off, the active account keeps generating with Anlas.
- Fixed prompt presets picking up the previous preset's parameters: switching to a preset with no or partial stored parameters kept the old steps, sampler and so on, and editing the prompt then saved them into the new preset. Missing values are now the model's defaults, and a slow start no longer overwrites the active preset with defaults.
- Scene JSON import reads every format NAIS2 accepted: NAIS2 scene exports, `scene_preset_export.json`, interaction-share slot files and SDImageGenEasy presets, and explains files it can't read.
- Cancelling reserved scene generations gives the reservations back to their scene and cast, keeping reservations added meanwhile.
- Images with the same seed saved in the same second (upscale, Director, local edits) no longer overwrite each other; later ones get `_2`, `_3`, ….
- Database migrations run in a worker thread, so relaunching during a long upgrade no longer restarts it, and the upgrade progress window is never left behind.

Database schema stays at **v20**. Updating from 1.0.28 or 1.0.29 needs no migration; from 1.0.27 or earlier, v18 moves to v20 with an automatic backup first.
