## 주요 변경

- **Anlas 지킴이 (선택)**: 설정 → 생성에 두 가지 보호 장치를 추가했습니다. 기본값은 꺼짐입니다.
  - **유료 요청 막기**: Anlas가 드는 요청은 보내지 않고, 해상도·스텝·바이브·캐릭터 레퍼런스·V5 게이지 소진 등 어떤 이유로 유료인지 알려 줍니다. 메인 화면에서는 생성 버튼을 누르기 전에 프롬프트 패널에 미리 표시합니다.
  - **하루 Anlas 한도** (켜면 기본 100): 오늘 쓴 Anlas와 다음 요청 예상치의 합이 한도를 넘으면 보내지 않습니다. 무료 요청은 항상 통과합니다.
- **NAI 토큰 보호**: 키체인이 잠겨 있거나 쓸 수 없는 상태로 앱을 켜면 저장된 계정 토큰이 모두 지워지던 문제를 고쳤습니다. 이제 잠긴 상태로 표시하고 아무것도 덮어쓰지 않으며, 필요하면 잠긴 토큰을 직접 지울 수 있습니다. OS 키체인 없이 토큰이 저장될 때도 미리 알려 줍니다.
- **삭제한 씬의 대기 생성 취소**: 씬을 지워도 대기열에 남은 생성이 계속 실행되어 Anlas를 쓰고 이미지가 사라지던 문제를 고쳤습니다. 지운 씬의 대기 작업은 취소되고, 이미 생성 중인 작업은 일반 히스토리에 저장됩니다.
- **백업 복원 후 씬 연결 유지**: 백업을 복원하면 생성 이미지와 씬의 연결이 모두 끊겨 씬 갤러리·표지·이미지 수가 비던 문제를 고쳤습니다.
- **설치 파일 크기 정상화**: 1.0.28부터 Mac·Windows 설치 파일에 불필요한 파일이 들어가 크기가 두 배가 되었던 문제를 고쳤습니다 (예: Mac Apple Silicon ZIP 약 258 MB → 133 MB, Windows 설치 파일 약 229 MB → 113 MB).
- **Electron 45로 업그레이드**: 지원이 끝난 Electron 39에서 최신 Electron 45(Chromium 156)로 올려 보안 업데이트를 다시 받습니다. 파일 열기·저장 창은 마지막으로 고른 폴더에서 열립니다.
- **화면 축소 단축키**: Cmd/Ctrl+`-`로 화면을 다시 축소할 수 있습니다.
- **화면 전환 다듬기**: 첫 실행 안내가 로고 인트로와 함께 부드럽게 나타나고, 좌우 패널이 페이지 넘김 동작으로 접히고 펼쳐집니다.

## 기존 사용자 데이터

이번 버전은 데이터베이스 스키마 **v20을 유지**합니다. 1.0.28~1.0.30에서 업데이트하면 마이그레이션 없이 바로 열립니다. 1.0.27 이하에서 업데이트하면 v18에서 v20으로 올라가며, 업그레이드 전에 기존 DB가 자동 백업됩니다.

## Highlights

- Optional Anlas guard under Settings → Generation, off by default:
  - Block paid requests: a request estimated to cost Anlas isn't sent, and the message says why (resolution, steps, vibes, character reference, an exhausted V5 gauge, and so on). In main mode the prompt panel shows the reasons before you press Generate.
  - Daily Anlas cap (100 when enabled): today's spending plus the next request's estimate must stay within the cap. Free requests always pass.
- Saved NAI tokens are no longer wiped when the app starts with a locked or unavailable keychain. The store is shown as locked, nothing is overwritten, and locked tokens can be deleted on purpose. The app also warns before saving tokens without the OS keychain.
- Deleting a scene cancels its queued generations, which used to keep running, spend Anlas and lose the image. Jobs already generating are saved to plain history.
- Restoring a backup keeps generation images linked to their scenes, so scene galleries, covers and counts no longer come back empty.
- Mac and Windows installers are back to their normal size. Since 1.0.28 they carried unneeded files and were about twice as large (for example, the Mac Apple Silicon ZIP went from about 258 MB to 133 MB, and the Windows installer from about 229 MB to 113 MB).
- Upgraded from Electron 39, which no longer receives security fixes, to Electron 45 (Chromium 156). Open and save dialogs start in the folder you picked last.
- Cmd/Ctrl+`-` zooms the UI out again.
- First-run onboarding opens with a smooth logo intro, and the side panels collapse and expand with the page-turn motion.

Database schema stays at **v20**. Updating from 1.0.28–1.0.30 needs no migration; from 1.0.27 or earlier, v18 moves to v20 with an automatic backup first.
