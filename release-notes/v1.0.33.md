## 주요 변경

- **V5 Precise Reference**: V5에서 캐릭터 레퍼런스에 **의상(Outfit)** 타입과 **같은 의상 우선** 스위치가 생겼습니다. V5에서는 강도를 최대 5까지 올릴 수 있고 Fidelity는 숨겨집니다. 레퍼런스 이미지는 NovelAI 웹과 같은 방식으로 맞춰 자릅니다. 다른 모델로 바꾸면 강도는 그 모델의 최대값으로 잘려서 전송됩니다.
- **이미지를 레퍼런스로 보내기**: 히스토리·미리보기·라이트박스·씬·라이브러리의 이미지 우클릭 메뉴에서 바로 바이브 트랜스퍼나 캐릭터 레퍼런스로 추가할 수 있고, 레퍼런스 패널에 이미지를 끌어다 놓을 수도 있습니다.
- **메타데이터에서 바이브 복원 (선택)**: 바이브 트랜스퍼로 만든 이미지의 메타데이터 창에서 바이브를 체크하면, 원본 레퍼런스 이미지가 없어도 그 바이브를 그대로 다시 켭니다. 기본값은 꺼짐이라 프롬프트만 적용할 때는 지금 켜 둔 바이브가 바뀌지 않습니다. 인코딩된 모델을 알 수 없는 이미지는 모델을 직접 고르게 합니다.
- **같은 설정으로 다시 생성**: 이미지 우클릭 메뉴의 **다시 생성**은 그 이미지의 설정으로 시드만 바꿔 한 장을 대기열에 넣습니다. 에디터의 프롬프트·설정은 건드리지 않습니다. I2I·인페인트 결과는 지원하지 않습니다.
- **무료 배경 제거 (Hugging Face)**: 디렉터의 무료 도구에 Hugging Face Space를 쓰는 배경 제거가 추가됐습니다. 이미지는 외부 서비스로 전송되므로 처음 쓸 때 안내를 확인한 뒤에만 실행되고, 보내기 전에 프롬프트 같은 생성 정보는 이미지에서 지웁니다. BRIA RMBG 2.0 모델은 비상업 라이선스(CC BY-NC 4.0)입니다.
- **프롬프트 프리셋 복제**: 프리셋 목록에 복제 버튼이 생겼습니다.
- **사라진 데이터 찾기·백업 복원**: 작업 공간이 비어 있는데 데이터가 든 백업이 남아 있으면 시작할 때 알려 줍니다. 설정 → 저장에서 앱이 보관한 백업 목록을 보고 바로 복원할 수 있으며, 복원 전 현재 상태도 따로 저장해 둡니다.
- **업그레이드·가져오기 전 DB 사본**: 앞으로 데이터베이스 버전이 올라가기 전과 .nais·JSON 백업을 가져오기 전에 기존 DB를 그대로 복사해 둡니다.
- **가벼워진 백업 내보내기**: .nais 백업과 씬 ZIP을 파일 하나씩 디스크에 바로 써서, 큰 작업 공간을 내보낼 때 메모리 사용량과 멈춤이 크게 줄었습니다.
- **빠른 태그 자동완성**: 태그 검색을 별도 스레드로 옮겨 첫 추천이 뜰 때 앱이 잠깐 멈추던 현상이 없어졌습니다.
- **macOS Liquid Glass 아이콘**: macOS 26 이상에서 시스템 아이콘 스타일에 맞는 새 앱 아이콘을 씁니다.

## 기존 사용자 데이터

이번 버전은 데이터베이스 스키마 **v20을 유지**합니다. 1.0.28~1.0.32에서 업데이트하면 마이그레이션 없이 바로 열립니다. 1.0.27 이하에서 업데이트하면 v18에서 v20으로 올라가며, 업그레이드 전에 기존 DB가 자동 백업됩니다.

이번 버전에서 메타데이터로 복원한 바이브와 V5 의상 레퍼런스는 이전 버전으로 되돌아가면 제대로 쓸 수 없습니다.

## Highlights

- V5 Precise Reference: Character Reference on V5 adds an **Outfit** type and a **Prefer same outfit** switch. Strength goes up to 5 on V5 and Fidelity is hidden. Reference images are cropped the same way as the NovelAI web client. On other models, strength is clamped to that model's limit when sent.
- Send any image to Vibe Transfer or Character Reference from the image context menu in history, preview, lightbox, scenes and library, or drop images onto the reference panel.
- Optional vibe restore from metadata: in the metadata dialog of an image made with Vibe Transfer, check vibes to enable exactly those vibes again, even without the original reference images. It is off by default, so applying only the prompt leaves your enabled vibes alone. If the encoding model can't be identified, you pick it.
- **Regenerate** in the image context menu queues one image with the same settings and a new seed, without touching the editor. I2I and inpainting results aren't supported.
- Free background removal in the director through Hugging Face Spaces. The image is sent to a third-party service, so it runs only after you confirm the notice the first time, and generation metadata such as the prompt is stripped before upload. The BRIA RMBG 2.0 model is licensed CC BY-NC 4.0 (non-commercial).
- Duplicate button for prompt presets.
- Lost data recovery: if the workspace is empty but a backup with data exists, NAIS3 offers it at startup. Settings → Storage lists the backups the app keeps and restores one in place, saving the current state first.
- NAIS3 now keeps an untouched copy of the database before a schema upgrade and before importing a .nais or JSON backup.
- .nais backups and scene ZIPs are streamed to disk file by file, which greatly reduces memory use and stalls when exporting large workspaces.
- Tag autocomplete runs off the main thread, so the first suggestion no longer freezes the app briefly.
- New Liquid Glass app icon on macOS 26 and later.

Database schema stays at **v20**. Updating from 1.0.28–1.0.32 needs no migration; from 1.0.27 or earlier, v18 moves to v20 with an automatic backup first. Vibes restored from metadata and V5 Outfit references don't work correctly if you go back to an earlier version.
